# Хронос для Foundry VTT 14

Компактная панель игрового времени, календарь и часы событий. Версия `0.1.0-beta.1` проверена в Foundry VTT 14.364.

## Установка

В Foundry откройте **Дополнения → Установить модуль** и вставьте Manifest URL:

`https://raw.githubusercontent.com/Jerrvik/chronos/main/module.json`

Включите модуль в нужном мире. Панель «Хронос» появится у мастера и игроков.

## Использование

- Значок ▦ открывает календарь. Значок ⚙ у мастера открывает управление. Панель можно перетащить и свернуть до маленького квадрата.
- Мастер переводит игровое время на час, день или следующую ночь либо задаёт дату и точное время вручную. Игровые часы сами не идут.
- Мастер создаёт общие и закрытые календарные события, публичные, анонимные и закрытые часы событий. Часы могут идти по ходам, по реальному времени или по ручной шкале.
- Отдельный таймер спотлайта по умолчанию рассчитан на 15 минут реального времени. Его видит только мастер; игрок выбирается вручную.

Общие данные сохраняются в мире Foundry и синхронизируются между клиентами. Закрытые события, названия анонимных угроз, закрытые часы и спотлайт хранятся **в браузере мастера**. Используйте для мастера отдельный профиль браузера и не очищайте данные сайта: при смене браузера или профиля эти записи не восстановятся. Foundry V14 передаёт содержимое документов мира клиентам даже при правах `NONE`, поэтому для секретов не используется серверное хранилище Foundry.

Модуль не меняет `game.time.worldTime`, освещение сцен и время других календарных модулей. Звуковые сигналы зависят от разрешений браузера и могут быть заблокированы до первого взаимодействия со страницей.
